# SyncFlow bèta

Dit is de officiële downloadplaats voor testversies van SyncFlow. SyncFlow
wisselt bestanden en privéklembordtekst versleuteld uit tussen Android, Linux
en Windows, rechtstreeks via het lokale netwerk of via internet.

## Downloaden

Open **Releases** aan de rechterkant van deze pagina en kies de nieuwste
vooruitgave:

- **Windows:** `SyncFlow-Setup-<versie>.exe`
- **Ubuntu/Debian:** `syncflow_<versie>_amd64.deb`
- **Fedora:** `syncflow-<versie>-1.x86_64.rpm`

Android wordt hier toegevoegd zodra de definitieve ondertekensleutel veilig is
ingesteld. Tot dan gebruiken Android-testers de besloten testinstallatie.

## Belangrijk

Dit is bètasoftware. Maak een back-up van belangrijke bestanden en gebruik voor
de eerste tests een aparte synchronisatiemap. Windows kan bij deze vroege bèta
nog waarschuwen dat de uitgever onbekend is; publieke codeondertekening volgt.

De broncode en geheime serverinstellingen staan niet in deze openbare
downloadrepository. Controleer na het downloaden de SHA-256-checksums in de
releasebeschrijving.

## Feedback

Meld een probleem via het supportkanaal dat bij de testuitnodiging is vermeld.
Vermeld het platform, de SyncFlow-versie en wat je vlak voor de fout deed. Deel
nooit koppelcodes, wachtwoorden of privébestanden.
